# 🎬 Avatar: The Last Airbender — Movie Website Challenge

## Four Nations. One Destiny.
A responsive promotional website built for the **Animation** category of the Movie Website Challenge. This project introduces visitors to the world of Avatar, showcases the main characters with interactive wiki links, provides a detailed story synopsis, and includes video trailers and theatre ticket booking links.

---

## 📋 Project Overview
Our team designed and developed this promotional web page to deliver an immersive fan experience while demonstrating a collaborative software development workflow. Key features include:
- **Hero Section:** Eye-catching movie title, tagline, and background styling representing the four elements.
- **Synopsis Section:** Detailed breakdown of the premise, the awakening, the journey, and the character conflicts.
- **Character Showcase:** Cards featuring Katara, Toph, Zuko, and Aang with element styling and direct links to their character wikis.
- **Interactive Call-to-Action:** Embedded YouTube trailer and direct theatre ticketing links.
- **Responsive Design:** Fully optimized for both desktop and mobile viewports using Tailwind CSS.

## 🏗️ Technical Architecture & Stack
- **Frontend Structure:** Semantic HTML5 (`index.html`)
- **Styling & Layout:** Tailwind CSS (via CDN) with custom theme configuration for element colors (Water, Earth, Fire, Air)
- **Interactivity:** Embedded YouTube iframe (`[Trailer](https://trello.com/c/uG4x8aKk/22-trailer-section)`), external wiki character links, and theatre ticket booking buttons
- **Version Control:** [GitHub](https://trello.com/c/Mw6Jvdqx/7-github-repository-setup) for collaborative pull requests, branching, and code merging
- **Project Management:** [Trello Board](https://trello.com/b/EG5dpqxW/movie-website-challenge#trello-board-root) for task tracking and agile sprint management
